# 📘 Exercício 01 — Estrutura Condicional (Switch)

Este exercício implementa um **menu de operações matemáticas** utilizando a estrutura `switch`.

Operações disponíveis:

1. Somar dois números
2. Subtrair dois números
3. Multiplicar dois números
4. Dividir dois números
5. Calcular raiz quadrada

Conceitos utilizados:

* Estrutura `switch`
* Entrada de dados com `Scanner`
* Operações matemáticas
* Validação de divisão por zero

# 🔁 Exercício 02 — Estruturas de Repetição

## Identificação de Meses

O programa recebe um número de **1 a 12** e exibe o **mês correspondente**.

Exemplo:
```
1 → Janeiro
2 → Fevereiro
3 → Março
...
12 → Dezembro
```

Caso o número seja inválido, o programa exibe:

Mês inválido

O programa continua executando até o usuário digitar **0**.

### Conceitos utilizados

* Estrutura `while`
* Estrutura `switch`
* Controle de fluxo



## Contagem de Idades

O programa solicita a **idade de 10 pessoas** e calcula quantas possuem **idade maior ou igual a 18 anos**.

Exemplo de saída:
```
Quantidade de pessoas com idade maior ou igual a 18 anos: 6
```

### Conceitos utilizados

* Estrutura `for`
* Arrays
* Contadores
* Entrada de dados

# 📊 Exercício 03 — Arrays em Java

## Alteração de Valores do Array

O programa solicita **10 números inteiros** e armazena em um array.

Depois realiza:

* Número **par → soma +1**
* Número **ímpar → subtrai -1**

Ao final o programa mostra:

* Valores antigos
* Valores modificados

### Conceitos utilizados

* Arrays
* Estrutura `for`
* Operador `%` (módulo)



## Análise de Números Pares e Ímpares

O programa solicita **10 números inteiros** e calcula:

* Quantidade de números pares
* Quais são os números pares
* Quantidade de números ímpares
* Quais são os números ímpares

Exemplo:
```
Quantidade de números pares: 4
Números pares: 2 8 10 14

Quantidade de números ímpares: 6
Números ímpares: 1 3 5 7 9 11
```

### Conceitos utilizados

* Arrays
* Estrutura `for`
* Condições (`if`)
* Operador módulo `%`
